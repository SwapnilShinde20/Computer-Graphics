# Experiment 7 – Sutherland-Hodgman Polygon Clipping

## 1. Concept samajh

Polygon matlab koi bhi closed shape, jaise triangle, rectangle, pentagon.

Clipping ka matlab hai polygon ka jo portion rectangular window ke bahar hai, usko remove karna.

Main concept: Polygon ko window ki 4 boundaries ke against ek-ek karke check karte hain.

1. Left boundary
2. Right boundary
3. Bottom boundary
4. Top boundary

Har boundary ke baad jo new polygon milta hai, usko next boundary ke liye use karte hain.

# 3. Short and Easy C Code

Is code mein sirf 3 functions hain:

- `inside()` – point inside hai ya outside check karega.
- `intersection()` – boundary ke saath intersection find karega.
- `clip()` – 4 cases apply karke polygon clip karega.

## Complete code

```
#include<stdio.h>
#include<conio.h>
#include<graphics.h>

float x[20],y[20],nx[20],ny[20];
float xmin=150,ymin=100,xmax=450,ymax=350;
float ix,iy;
int n;

int inside(float x,float y,int edge)
{
    if(edge==0) return x>=xmin;  // Left
    if(edge==1) return x<=xmax;  // Right
    if(edge==2) return y>=ymin;  // Bottom
    if(edge==3) return y<=ymax;  // Top
    return 0;
}

void intersection(float x1,float y1,float x2,float y2,int edge)
{
    if(edge==0 || edge==1)
    {
        ix=(edge==0)?xmin:xmax;
        iy=y1+(y2-y1)*(ix-x1)/(x2-x1);
    }
    else
    {
        iy=(edge==2)?ymin:ymax;
        ix=x1+(x2-x1)*(iy-y1)/(y2-y1);
    }
}

void clip(int edge)
{
    int i,j=0;
    float sx,sy,ex,ey;

    sx=x[n-1];
    sy=y[n-1];

    for(i=0;i<n;i++)
    {
        ex=x[i];
        ey=y[i];

        if(inside(sx,sy,edge) && inside(ex,ey,edge))
        {
            nx[j]=ex;
            ny[j++]=ey;
        }
        else if(inside(sx,sy,edge) && !inside(ex,ey,edge))
        {
            intersection(sx,sy,ex,ey,edge);
            nx[j]=ix;
            ny[j++]=iy;
        }
        else if(!inside(sx,sy,edge) && inside(ex,ey,edge))
        {
            intersection(sx,sy,ex,ey,edge);
            nx[j]=ix;
            ny[j++]=iy;

            nx[j]=ex;
            ny[j++]=ey;
        }

        sx=ex;
        sy=ey;
    }

    n=j;

    for(i=0;i<n;i++)
    {
        x[i]=nx[i];
        y[i]=ny[i];
    }
}

void drawPolygon()
{
    int i;

    for(i=0;i<n;i++)
        line(x[i],y[i],x[(i+1)%n],y[(i+1)%n]);
}

void main()
{
    int gd=DETECT,gm,i;

    initgraph(&gd,&gm,"C:\\TURBOC3\\BGI");

    n=5;

    x[0]=100; y[0]=150;
    x[1]=300; y[1]=50;
    x[2]=500; y[2]=150;
    x[3]=400; y[3]=400;
    x[4]=180; y[4]=300;

    setcolor(WHITE);
    rectangle(xmin,ymin,xmax,ymax);

    setcolor(RED);
    drawPolygon();

    outtextxy(200,50,"BEFORE CLIPPING");
    getch();

    cleardevice();

    /* CLIP AGAINST FOUR EDGES */

    for(i=0;i<4;i++)
        clip(i);

    setcolor(WHITE);
    rectangle(xmin,ymin,xmax,ymax);

    setcolor(GREEN);
    drawPolygon();

    outtextxy(200,50,"AFTER CLIPPING");

    getch();
    closegraph();
}
```

# 4. Code line-by-line explanation

## A. Arrays

```
float x[20],y[20],nx[20],ny[20];
```

- `x[]` = Original polygon ke X coordinates.
- `y[]` = Original polygon ke Y coordinates.
- `nx[]` = New polygon ke X coordinates.
- `ny[]` = New polygon ke Y coordinates.

```
int n;
```

Polygon mein kitne vertices hain.

## B. Inside function

```
int inside(float x,float y,int edge)
```

Ye check karta hai ki point clipping boundary ke andar hai ya bahar.

```
if(edge==0) return x>=xmin;
if(edge==1) return x<=xmax;
if(edge==2) return y>=ymin;
if(edge==3) return y<=ymax;
```

| Edge | Condition |
| ---- | --------- |
| 0    | Left      |
| 1    | Right     |
| 2    | Bottom    |
| 3    | Top       |

Agar condition true hai toh `1` return karega, otherwise `0`.

## C. Intersection function

```
void intersection(float x1,float y1,float x2,float y2,int edge)
```

Jab ek point inside aur doosra outside ho, tab intersection calculate karta hai.

```
if(edge==0 || edge==1)
```

Left aur Right boundary vertical hain.

Isliye X fixed rahega aur Y calculate hoga.

```
ix=(edge==0)?xmin:xmax;
```

Left hai toh XMIN, otherwise XMAX.

```
iy=y1+(y2-y1)*(ix-x1)/(x2-x1);
```

Y coordinate calculate karta hai.

Similarly:

```
else
```

Bottom aur Top boundary horizontal hain.

```
iy=(edge==2)?ymin:ymax;
ix=x1+(x2-x1)*(iy-y1)/(y2-y1);
```

Y fixed rahega aur X calculate hoga.

```

{
    x[i]=nx[i];
    y[i]=ny[i];
}
```

New vertices ko original arrays mein copy kar dete hain.

Ab next boundary ke liye updated polygon ready hai.

## F. Main function

```

```

Most important line

- `clip(0)` – Left
- `clip(1)` – Right
- `clip(2)` – Bottom

# 6. Important Viva Questions

| Question                  | Answer                                            |
| ------------------------- | ------------------------------------------------- |
| What is polygon clipping? | Removing polygon portions outside the window.     |
| Which algorithm?          | Sutherland-Hodgman.                               |
| How many boundaries?      | Four.                                             |
| What is a vertex?         | Corner point of a polygon.                        |
| What is intersection?     | Point where polygon edge meets clipping boundary. |
| How many cases?           | Four.                                             |
| What is `inside()`?       | Checks whether point is inside.                   |
| What is `clip()`?         | Performs polygon clipping.                        |
| What is `nx[]`?           | Stores new X coordinates.                         |
| What is `ny[]`?           | Stores new Y coordinates.                         |

Advantages: Easy to implement, processes vertices one by one.

Disadvantage: Requires considerable memory to store intermediate polygons.
