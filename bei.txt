## 3. Formula samajh

PDF mein general Bezier formula use hua hai:

\\[ B(t)=\sum\_{j=0}^{n-1} C(n-1,j)(1-t)^{n-1-j}t^jP_j \\]

Tension mat le! Iska simple meaning:

- `t` = 0 se 1 tak change hota hai.
- `n` = Total control points.
- `j` = Current control point.
- `C(n-1,j)` = Combination.
- `Pj` = Current control point.

X aur Y separately calculate karte hain:

\\[ x=\sum b\times x_j \\]

\\[ y=\sum b\times y_j \\]

Where:

\\[ b=C(n-1,j)(1-t)^{n-1-j}t^j \\]

Code mein bas ye formula use karenge.

# 4. Short and Easy C Code

Simplified practical code

```
#include<stdio.h>
#include<conio.h>
#include<graphics.h>
#include<math.h>

void main()
{
    int gd=DETECT,gm;
    int n,i,j,k;
    int x[20],y[20];
    double t,b,xt,yt;

    initgraph(&gd,&gm,"C:\\TURBOC3\\BGI");

    printf("Enter number of control points: ");
    scanf("%d",&n);

    if(n<2 || n>10)
    {
        printf("Invalid number of points");
        getch();
        closegraph();
        return;
    }

    for(i=0;i<n;i++)
    {
        printf("Enter P%d (x y): ",i);
        scanf("%d%d",&x[i],&y[i]);
    }

    setcolor(WHITE);

    for(i=0;i<n-1;i++)
        line(x[i],y[i],x[i+1],y[i+1]);

    setcolor(YELLOW);

    for(t=0;t<=1;t+=0.001)
    {
        xt=0;
        yt=0;

        for(j=0;j<n;j++)
        {
            b=1;

            for(k=1;k<=j;k++)
                b=b*(n-k)/k;

            b=b*pow(t,j)*pow(1-t,n-1-j);

            xt=xt+b*x[j];
            yt=yt+b*y[j];
        }

        putpixel((int)xt,(int)yt,YELLOW);
    }

    getch();
    closegraph();
}
```

```

```

Saare control points ko straight lines se connect karta hai.

White lines = Control polygon.

### G. Bezier curve draw karna

```
setcolor(YELLOW);

for(t=0;t<=1;t+=0.001)
```

`t` ki value 0 se 1 tak increase hoti hai.

Har value par curve ka ek point calculate hota hai.

Example:

```
t = 0
t = 0.001
t = 0.002
...

```

Jitne zyada points calculate honge, curve utni smooth dikhegi.

### H. Coordinates initialize

```
xt=0;
yt=0;
```

Har new `t` value ke liye X aur Y ko zero se start karte hain.

### I. Combination calculation

```
for(j=0;j<n;j++)
{
    b=1;

    for(k=1;k<=j;k++)
        b=b*(n-k)/k;
```

Ye combination calculate karta hai:

\\[ C(n-1,j) \\]

Example: Agar 4 control points hain toh combination values:

| j | Combination |
| - | ----------- |
| 0 | 1           |
| 1 | 3           |
| 2 | 3           |
| 3 | 1           |

### J. Main Bezier formula

```
b=b*pow(t,j)*pow(1-t,n-1-j);
```

Ye formula ka blending part calculate karta hai:

\\[ b=C(n-1,j)t^j(1-t)^{n-1-j} \\]

`pow(a,b)` means \\(a^b\\).

### K. X and Y calculate

```
xt=xt+b*x[j];
yt=yt+b*y[j];
```

Har control point ka contribution add hota hai.

\\[ x=\sum b x_j \\]

\\[ y=\sum b y_j \\]

### L. Pixel draw

```
putpixel((int)xt,(int)yt,YELLOW);
```

Calculated coordinate par yellow pixel draw karta hai.

Saare pixels milkar smooth Bezier Curve banate hain.

### M. End

```
getch();
closegraph();
```

Key press hone ka wait karta hai aur graphics window close karta hai.

# 7. Important Properties of Bezier Curve

PDF ke page 1–2 ke according:

1. Curve first aur last control points se pass hoti hai.
2. Generally control polygon ka shape follow karti hai.
3. Curve control points ke convex hull ke andar rehti hai.
4. Degree = Number of control points − 1.
5. Ek control point move karne se poori curve ka shape change ho sakta hai.
6. Curve smooth hoti hai.

# 8. Important Viva Questions

| Question                                           | Answer                                               |
| -------------------------------------------------- | ---------------------------------------------------- |
| What is Bezier curve?                              | A smooth parametric curve defined by control points. |
| What are control points?                           | Points used to control curve shape.                  |
| Quadratic Bezier requires?                         | 3 control points.                                    |
| Cubic Bezier requires?                             | 4 control points.                                    |
| Degree of Bezier curve?                            | n − 1                                                |
| What is t?                                         | Parameter between 0 and 1.                           |
| What is `pow()`?                                   | Calculates power.                                    |
| What is `putpixel()`?                              | Draws a pixel at given coordinates.                  |
| Does curve pass through first and last points?     | Yes.                                                 |
| Does it always pass through middle control points? | No.                                                  |

Q. What is global control?

Moving one control point can change the shape of the entire Bezier curve.

Q. What is the use of Bezier curves?

Used in computer graphics, vector graphics, animation and designing smooth shapes.
